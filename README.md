# SIMPAY

**Sistem Informasi Manajemen Pelayanan, Antrean, dan Layanan Medis Berbasis Web di Klinik Praktik Dokter Umum.**

## 📌 Tentang SIMPAY

SIMPAY adalah sistem informasi berbasis web yang membantu dokter dan perawat dalam mengakses informasi serta riwayat pasien secara lebih cepat dan terstruktur.

## 🎯 Target User

- Dokter
- Perawat

## 💡 Core Value

Mempermudah dan mempercepat akses informasi pasien.

## 🔄 Core User Flow

Cari Pasien → Pilih Pasien → Lihat Riwayat Pasien

## 🚀 MVP

Fokus utama MVP:

1. Login
2. Dashboard
3. Pencarian pasien
4. Detail pasien
5. Riwayat pemeriksaan
