# SIMPAY

## Sistem Informasi Manajemen Pelayanan, Antrean, dan Layanan Medis Berbasis Web di Klinik Praktek Dokter Umum

SIMPAY adalah sistem berbasis web yang membantu dokter dan perawat dalam mengelola pelayanan, data pasien, antrean pemeriksaan, rekam medis, resep & obat, serta laporan klinik.

## 🎯 Tujuan Produk

Membantu tenaga medis mengurangi pengelolaan administrasi yang masih manual sehingga informasi pasien dapat diakses lebih cepat, mengurangi beban administrasi, dan meminimalkan risiko kesalahan pencatatan.

## 👥 Target User

- Dokter
- Perawat
- Admin Klinik

## ⭐ Core Value

Memudahkan tenaga medis mengakses dan mengelola informasi pasien dalam satu sistem.

## 📌 Fitur Utama

1. Data Pasien
2. Antrean Pemeriksaan
3. Rekam Medis
4. Resep & Obat
5. Laporan
